Web Assistant settings

Configure your API keys. You only need a key for the providers you want to use. Model selection lives on the side panel — switch any time without coming back here.

Used for Claude models (Opus, Sonnet, Haiku). Stored locally; only sent to api.anthropic.com. Get a key at console.anthropic.com/settings/keys.

Used for GPT and o-series models. Stored locally; only sent to api.openai.com. Get a key at platform.openai.com/api-keys.

Used for DeepSeek Chat and Reasoner models. Stored locally; only sent to api.deepseek.com. Get a key at platform.deepseek.com/api_keys.

Used for Qwen and QwQ models via Alibaba DashScope (international endpoint). Stored locally; only sent to dashscope-intl.aliyuncs.com. Get a key at dashscope.console.aliyun.com/apiKey.

Open the assistant via the extension icon in the toolbar, or with the keyboard shortcut you assign at chrome://extensions/shortcuts.
